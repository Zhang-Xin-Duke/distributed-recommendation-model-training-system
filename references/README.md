# Reference collection

Local research material is stored in `private/`, which is excluded from version control.

The collection includes a tracked-file snapshot of the upstream training framework, original Full Mirror page payloads, extracted text, code blocks, referenced attachments, and provenance manifests. Original source files remain at their original locations.

The local entry point is `private/RESEARCH_INDEX.txt`. Retrieval coverage and reading coverage are recorded separately; an archived document is not automatically marked as reviewed.

The independent service architecture is documented in `../docs/ARCHITECTURE.md`.
The local `private/DESIGN_SOURCE_MAP.md` connects its baseline to source symbols
and Full Mirror pages. Upstream source, internal documents, and historical
measurements remain research references; the tracked service interfaces and
design decisions describe this project's own work.
